# InsureAI

InsureAI is an AI-assisted insurance claims management platform built with React, TypeScript and Tailwind CSS.

## Project Overview

InsureAI is designed to streamline the insurance claims process by connecting policyholders, claims officers and administrators through a unified platform.

## Main Modules

- Customer dashboard
- Policy management
- Insurance claim submission
- Claim tracking
- Evidence and document management
- AI-assisted damage assessment
- Claims officer review
- Claim approval and rejection
- Admin dashboard
- Claims and policy analytics

## Technology

- React
- TypeScript
- Tailwind CSS
- Vite

## Current Status

The project is currently under development. The frontend prototype and user interfaces are being developed before integration with the backend and database.

## Development

Install dependencies:

    npm install

Start the development server:

    npm run dev

Create a production build:

    npm run build

## Data

Current claim and dashboard data are prototype data. They will be connected to the application's backend and database during integration.
